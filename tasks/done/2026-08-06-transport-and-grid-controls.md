# 再生ツールバーと拍グリッド調整の追加

## 要件

### A. 全体波形プレビューの上に再生ツールバーカードを追加

- [x] 再生 / 一時停止
- [x] 停止
- [x] 最初から
- [x] 1 小節戻る
- [x] 1 拍戻る
- [x] 1 拍進む
- [x] 1 小節進む

### B. 下部機能エリア

- [x] 4 拍モード / 3 拍モードの切り替え（単純に 3 拍にするだけ）
- [x] 拍の調節（新規）: スライダーの値はミリ秒。可動範囲は ±16 分音符ぶんの長さを
      テンポから算出（120BPM なら ±125ms、90BPM なら ±167ms）。1ms 刻み
- [x] 小節の頭: -3 拍〜+3 拍まで調整可能にする
- [x] 開始する小節（新規）: -3 小節〜+3 小節。音源の開始より手前は無音で埋める

## 前提（ユーザー確認済み）

- 再生 / 停止は新しい上のカードへ移す（下と二重には置かない）。下部には A/B 比較・
  ループ・音量・フェードが残る
- 「一時停止」があるので、再生位置は停止中も保持する状態になる

## 設計

### 拍グリッドを 1 本の連続したインデックス空間として扱う

位相 0〜3 では `ticks[0]` より手前を小節の頭にできない。開始インデックスに一般化した。

```
startIndex = estimatedPhase + beatShift + barShift * beatsPerBar
             （自動推定）    （-3〜+3拍）  （-3〜+3小節）
```

`startIndex` は負を取る。`gridTime(grid, index)` が範囲外を周辺の拍間隔で外挿するので、
負のインデックスは音源の手前（t < 0）を指す。スケジューラはその分を何もスケジュール
しないことで無音にし、出力タイムライン上の位置だけを進める。

拍の調節（±16 分音符）は `makeBeatGrid(ticks, offsetSeconds)` で全ての拍に等しくかかる。
全体が同じ量ずれるのでスライスの長さは変わらない。

### 残課題・申し送り

- 拍の調節は**絶対時間（ms）**で持つ。テンポの違う曲へ切り替えると可動幅が変わるので、
  範囲外に取り残さないよう effect でクランプしている
- 4 拍モードへ戻したとき、並び順が `231` のように新しい拍数でも成り立つ場合はそのまま
  残す（無効なときだけ既定値へ戻す）。小節長が 3/4 のままになるのは仕様
- 1 拍目の自動推定はヒューリスティックのまま。外した場合は「小節の頭」で直す
